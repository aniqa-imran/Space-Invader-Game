# Space-Invader-Game
A sleek, retro-inspired **Space Invaders** arcade game built with Python and Pygame. Featuring vibrant neon visuals, animated space backgrounds, particle explosion physics, multi-wave progression, and fluid controls.

---

## 🌟 Key Features

- **Neon Arcade Aesthetics:** Custom vector-drawn neon spaceships, UFO invaders, and dynamic color palettes.
- **Particle System:** Real-time particle physics effects for explosions when destroying enemy ships.
- **Dynamic Starfield Background:** Animated multi-layered scrolling background for an immersive space environment.
- **Wave Progression System:** Endless gameplay where enemy speed and spawn rates scale with each cleared wave.
- **Custom HUD:** Tracks current Score, Wave progress, and remaining Lives in real-time.

---

## 🎮 Game Controls

| Key / Input | Action |
| :--- | :--- |
| **A** / **Left Arrow** | Move Spaceship Left |
| **D** / **Right Arrow** | Move Spaceship Right |
| **Spacebar** | Fire Lasers / Start Game |
| **R** / **Mouse Click** | Restart Game (Game Over Screen) |

---

## 🛠️ Prerequisites & Installation

### 1. Requirements
Ensure you have **Python 3.8+** installed on your system.

### 2. Install Pygame
Open your terminal or command prompt and run:
pip install pygame

Run the main script:

python main.py
